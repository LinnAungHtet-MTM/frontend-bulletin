# React + TypeScript + Vite

This project is a frontend web application built with **React**, **Vite**, and **TypeScript**.

---

## 🛠 Tech Stack

- **React** – UI Library
- **Vite** – Build Tool & Dev Server
- **TypeScript** – Static Typing
- **ESLint** – Code Linting
- **Prettier** – Code Formatting
- **Tailwind / ShadcnUI** – UI Components

---

## 🚀 Getting Started

### 1️⃣ Clone Repository

```bash
git clone https://github.com/LinnAungHtet-MTM/frontend-bulletin.git
cd frontend-bulletin
```

### 2️⃣ Install Dependencies

```bash
npm install
```

## 3️⃣ Copy .env.example to .env

```bash
cp .env.example .env
```

## 4️⃣ Run Development Server
```bash
npm run dev
```
